# D7 처방 보드

게임의 출시 후 7일차(D7) 데이터를 넣으면, 어떤 처방(충돌률 개선·플레이타임·업데이트 주기·마케팅 예산)을 하면 90일 예상 매출이 얼마가 되는지 보여 주는 진단 도구.
DArt-B × Parrot 데이터톤(앵날다쏘 2026) 4조 MVP.

- 화면: ① 게임 진단(입력 → 처방별 예상 90일 매출) ② 전체 게임 비교(품질 × 마케팅비 매트릭스, 우선순위) ③ 실험카드
- 진단 로직: `scripts/priority_pipeline.py` (팀 파이프라인, 셀 = 장르 × 과금방식)
  - 셀 = 장르 × 과금방식(Free·Freemium·Paid·Subscription), 50개 미만 셀은 같은 과금방식 전체로 대체
  - 품질 = 마케팅비를 뺀 D7 지표로 예측한 로그 매출(선형회귀, train 5-fold 교차적합)의 셀 안 백분위
  - 마케팅비 셀 안 백분위, 사분면(백분위 50), 우선순위 점수 = 품질 백분위 × (1 − 마케팅비 백분위)
- 예측 매출: 팀 최종 앙상블(CV RMSLE 0.6741). 직접 입력 시 팀 내부 회귀 모델(마케팅비 포함)
- 데이터는 교육용 합성 데이터. 모든 예상치는 상관 기반이며 인과 효과가 아님

## 수정 방법
1. `src/mvp_template.html` 수정 (데이터는 `data/` JSON)
2. `python3 build.py` → `index.html` 생성
3. commit & push → GitHub Pages 자동 반영
